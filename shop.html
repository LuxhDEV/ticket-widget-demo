Was passiert hier?

Diese Variante nutzt nur offizielle Enviso-Widget-Elemente: enviso-offer-overview, enviso-ticket-flow, enviso-basket-flow, enviso-basket-button, enviso-basket-expiry-countdown, enviso-ticket-order-complete-step. Kein eigener API-Aufruf, keine eigenen Angebotskarten. Unser JavaScript blendet nur Bereiche ein/aus und setzt Attribute aus dokumentierten Events.

Tickets

Wähle ein Angebot und klicke auf „Tickets“.

Was passiert hier?

Element <enviso-offer-overview offer-type="ticket" included-offer-ids="[…]"> lädt und zeigt die Angebote selbst. Dokumentiertes Event buyticketsclick → wir zeigen den Buchungsbereich mit <enviso-ticket-flow offer-id="…">.

Tickets buchen

Was passiert hier?

Element <enviso-ticket-flow offer-id="…"> enthält Ticketauswahl, Datum/Zeitfenster und den Button „In den Warenkorb“ – die Reservierung legt das Element selbst an. Das Warenkorb-Symbol oben zählt danach hoch. Weiter geht es über „Zum Warenkorb“ (der Ticket-Flow selbst hat dafür kein dokumentiertes Event).

Warenkorb & Kasse

Was passiert hier?

Element <enviso-basket-flow>: Bestellübersicht (ändern/löschen) → Meine Info → Zahlung, alles im Element. Die Zahlung legt die Bestellung an (Event ordercreated), danach paymentverified/paymentfailed. Im dokumentierten Slot continueShopping steckt nur ein normaler Link zurück zu den Tickets. Countdown: <enviso-basket-expiry-countdown threshold="30">.
