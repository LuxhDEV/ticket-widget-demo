Ticket Widget Demo

Static staging demo for the Enviso ticketing widget. Credentials are supplied only via URL query parameters and are not stored.

Custom flow built from the individual step components: steps.html (same URL parameters).

Configuration required

Open this page with the required query parameters. Values are used only in memory for this page load. Nothing is written to browser storage, cookies, or logs.

  • apikey – widget API key (required)
  • salespoint – sales point id (required)
  • offers – optional comma-separated offer ids
  • offer – optional single offer id (direct detail view)
  • lang / locale – optional language and locale
  • tenant – optional; accepted for compatibility, not a documented widget setting
  • apiurl – optional ticketing widget API base; default is staging

Example shape (replace placeholders yourself, do not commit real values): ?apikey=YOUR_KEY&salespoint=YOUR_SALESPOINT&offers=OFFER_A,OFFER_B

Docs: official Enviso ticketing widget docs, "Getting started"
